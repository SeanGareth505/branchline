Privacy

Branchline is a desktop Git client. Your repositories and credentials stay on your computer.

What stays on this machine

Recent repos, settings, and local crash reports are stored in Branchline’s app data (SQLite) on your device. GitHub / GitLab / Azure / Jira tokens are stored in the OS keychain when available, and otherwise in that local database. Tokens are redacted in the UI.

What we do not collect

Branchline does not phone home. There is no analytics, crash-upload, or account on a Branchline server. In-app updates download installer metadata from GitHub Releases.

GitHub sign-in

Device login requests the GitHub OAuth scopes repo, workflow, and read:user so Branchline can list pull requests, publish, and show your login. You can revoke access at GitHub → Applications.

Other hosts

GitLab, Azure DevOps, and Jira use personal access tokens you paste. They are stored in the OS keychain when available and sent only to those hosts when you use clone, PRs, or the Jira panel.
